# UI/UX 개편 기획서: Homefit 루틴 관리 시스템

이 문서는 Homefit 인터벌 타이머의 UI/UX를 단일 설정 방식에서 다중 루틴 관리 시스템으로 전환하기 위한 설계안을 담고 있습니다.

## 1. 주요 변경 사항 개요
기존의 긴 단일 페이지 구성을 독립적인 단계별 흐름으로 분리하고, 사용자 경험(UX)을 루틴 중심으로 개편합니다.

## 2. 네비게이션 및 페이지 구조

### 2.1 메인 페이지 (루틴 목록)
- **중앙 루틴 카드 섹션**: 사용자가 생성한 루틴들을 카드 형태로 나열.
- **루틴 카드 정보**: 루틴 이름, 총 소요 시간, 포함된 운동 개수 등 간략 정보 표시.
- **추가 버튼 (+)**: 
  - 루틴이 없을 경우 중앙에 크게 표시.
  - 루틴이 있을 경우 리스트 하단에 배치.
- **동작**: + 버튼 클릭 시 루틴 이름 입력 팝업/모달 표시 -> 이름 등록 후 해당 루틴 상세 페이지로 이동.

### 2.2 지정 루틴 페이지 (루틴 상세)
- **운동 카드 목록**: 해당 루틴에 포함된 운동들을 순서대로 표시.
- **운동 카드 정보**: 운동 이미지, 이름, 운동 시간(Work), 휴식 시간(Rest).
- **추가 버튼 (+)**: 하단에 배치하여 운동 선택 페이지로 연결.
- **시작 버튼 (고정)**: 화면 하단에 플로팅/고정 형태로 배치하여 즉시 운동 시작.

### 2.3 운동 선택 및 설정 페이지
- **운동 라이브러리**: 기존의 카테고리별/부위별 운동 리스트 활용.
- **운동 선택 시 동작**: 
  - 특정 운동 클릭 시 **운동 설정 모달** 팝업.
  - **iOS 스타일 시간 선택기 (Time Picker)**: 세로 스크롤 형태로 분/초를 직관적으로 선택.
  - 설정 완료 시 루틴에 추가되고 상세 페이지로 복귀.

## 3. 기술적 요구 사항
- **데이터 스키마**: 
  ```typescript
  interface Routine {
    id: string;
    name: string;
    exercises: {
      id: string;
      exerciseId: string; // 기본 운동 데이터 ID
      workTime: number;   // 초 단위
      restTime: number;   // 초 단위
    }[];
  }
  ```
- **상태 관리**: `localStorage`를 통해 여러 루틴을 `homefit_routines` 키로 관리.
- **UI 컴포넌트**: 
  - Framer Motion을 활용한 부드러운 페이지 전환 및 모달 애니메이션.
  - 세로 스크롤 형태의 커스텀 시간 선택기 구현.

## 4. 작업 우선순위
1. `localStorage` 데이터 구조 변경 및 관련 훅 업데이트.
2. 메인 페이지 루틴 목록 UI 구현.
3. 개별 루틴 상세 페이지 및 운동 카드 UI 구현.
4. 운동 선택 모달 및 iOS 스타일 시간 선택기 구현.
5. 전체 연동 및 타이머 로직 연결.
