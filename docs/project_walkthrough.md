# Homefit 인터벌 타이머 가이드

프리미엄 Homefit 인터벌 타이머에 오신 것을 환영합니다! 이 애플리케이션은 브라우저나 휴대폰에서 직접 원활하고 고품질의 운동 경험을 제공하도록 설계되었습니다.

## 🚀 주요 기능

### 1. 엄선된 운동 라이브러리
**50가지 맨몸 운동** 데이터셋을 통합했습니다.
- 각 운동에는 **한글 이름**, **설명**, **애니메이션 GIF** 시연이 포함되어 있습니다.
- 데이터는 [hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset)에서 동적으로 소싱됩니다.

### 2. 스마트 인터벌 타이머
- **운동/휴식 사이클**: 운동 및 휴식 시간을 자유롭게 설정할 수 있습니다.
- **오디오 안내**: Web Audio API를 사용한 실시간 비프음 피드백을 제공합니다.
  - *준비 (3초 전)*: 고음 비프음
  - *시작*: 다중 톤 비프음
  - *종료*: 저음 비프음
- **시각적 피드백**: 원형 진행 표시기와 함께 중앙에 크게 표시되는 카운트다운을 제공합니다.

### 3. 프리미엄 다크 에스테틱
- **디자인 시스템**: 세련된 다크 슬레이트와 선명한 퍼플 액센트 컬러 팔레트로 구축되었습니다.
- **애니메이션**: Framer Motion을 사용하여 운동 전환 시 부드러운 트랜지션을 제공합니다.
- **글래스모피즘**: 배경 흐림 효과와 섬세한 테두리로 현대적인 느낌을 줍니다.

### 4. PWA (점진적 웹 앱) 지원
- **설치 가능**: 아이폰/안드로이드 홈 화면에 추가하여 네이티브 앱처럼 사용할 수 있습니다.
- **지속성**: 사용자 정의 루틴은 기기의 LocalStorage에 자동으로 저장됩니다.

---

## 🛠️ 사용 방법

1. **루틴 만들기**:
   - 오른쪽의 운동 목록을 스크롤합니다.
   - **(+)** 버튼을 클릭하여 루틴에 운동을 추가합니다.
2. **시간 설정**:
   - "루틴 설정" 패널의 슬라이더를 사용하여 운동 및 휴식 시간을 조절합니다.
3. **운동 시작**:
   - 하단의 커다란 **START WORKOUT** 버튼을 클릭합니다.
4. **운동 중**:
   - 배경의 애니메이션을 따라 운동하세요.
   - 오디오 안내에 맞춰 운동과 휴식을 전환하세요.
