# 🏠 Homefit 사용자 가이드

Homefit은 오픈소스 운동 데이터셋을 활용한 고성능 HIIT 인터벌 타이머 웹 앱입니다. 이 문서는 앱의 주요 기능과 조작 방법을 설명합니다.

---

## 🚀 주요 기능

### 1. 루틴 관리 (Routine Management)
- **루틴 생성**: 메인 화면에서 '+' 버튼을 눌러 새로운 운동 루틴을 만들 수 있습니다.
* **운동 추가**: 루틴 상세 페이지 하단의 '운동 추가하기'를 누르면 ExerciseDB 기반의 400여 가지 운동 목록이 나타납니다. 검색과 카테고리 필터를 통해 원하는 운동을 선택하세요.
* **반복 횟수(Rounds) 설정**: 상단 요약 바의 '+', '-' 버튼을 통해 전체 루틴을 몇 번 반복할지 설정할 수 있습니다.

### 2. 제스처 조작 (Gestures)
운동 목록 카드에서 다음과 같은 스와이프 액션을 지원합니다:
* **오른쪽으로 밀기 (Swipe Right)**: 해당 운동의 **시간 설정 모달**이 열립니다. 운동 시간(WORK)과 휴식 시간(REST)을 5초 단위로 세밀하게 조절할 수 있습니다.
* **왼쪽으로 밀기 (Swipe Left)**: 해당 운동을 루틴에서 즉시 **삭제**합니다.
* **드래그 앤 드롭 (Drag & Drop)**: 카드 우측의 '그립 아이콘(⋮⋮)'을 잡고 위아래로 움직여 운동 순서를 바꿀 수 있습니다.

### 3. 인터벌 타이머 (Interval Timer)
* **총 소요 시간 자동 계산**: 루틴에 담긴 모든 운동과 휴식 시간, 반복 횟수를 계산하여 총 운동 시간을 실시간으로 보여줍니다.
* **시각적/음성 피드백**: 운동 상태에 따라 색상이 변화하며(운동: 초록, 휴식: 주황, 준비: 파랑), 매 단계 종료 3초 전부터 비프음 알림이 발생합니다.

## 🖼️ 오픈소스 운동 데이터 활용법

Homefit은 [hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset)의 데이터를 활용합니다.

- **GIF 이미지**: 각 운동의 정확한 자세를 보여주는 GIF 애니메이션이 포함되어 있습니다.
- **이미지 로딩**: 네트워크 상태에 따라 이미지가 늦게 뜰 경우, 로딩 스피너와 기본 아이콘이 표시되어 UX를 보호합니다.
- **데이터 구조**: `public/data/exercises.json` 파일에서 모든 운동 정보와 이미지 경로를 관리합니다.

- **State**: React Hooks, LocalStorage
