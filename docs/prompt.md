🛠️ 나만의 홈트 타이머 앱 제작을 위한 프롬프트
아래 내용을 복사하여 AI 개발 도구에 입력하세요.

[시스템 역할]
너는 Next.js와 Tailwind CSS 전문가이자 운동 생리학 지식이 풍부한 풀스택 개발자야. 혼자서 가볍게 사용할 수 있는 '나만의 인터벌 운동 타이머' 웹 앱을 만들 거야.

[핵심 요구사항]

No Database: 별도의 서버나 DB 없이 클라이언트 사이드에서만 작동하며, 설정값은 필요한 경우 로컬 스토리지를 활용해.

기술 스택: Next.js (App Router), Tailwind CSS, Lucide React (아이콘), Framer Motion (애니메이션).

주요 기능:

커스텀 루틴 생성: 운동 목록에서 동작을 선택하고 운동/휴식 시간을 설정하여 저장.

인터벌 타이머: 현재 운동 이미지, 남은 시간, 다음 동작을 시각적으로 명확하게 표시.

오디오 연동: 운동 시작/종료 시 알림음(Beep)과 함께 배경음악(Royalty-free) 재생 및 컨트롤 기능.

PWA 지원: 아이폰에서 '홈 화면에 추가'했을 때 네이티브 앱처럼 작동하도록 manifest.json 설정 포함.

[운동 데이터 세트 구성]

기구가 필요 없는 홈트레이닝 중심의 대표 운동 50가지를 JSON 형태로 생성해줘. (예: 푸쉬업, 스쿼트, 런지, 플랭크, 버피, 마운틴 클라이머 등)

각 운동 데이터는 id, name, description, imagePath, category(상체/하체/코어/전신)를 포함해야 해.

[UI/UX 디자인 지침]

다크 모드를 기본으로 하여 운동 중 눈이 편안하게 설계해줘.

운동 중에는 남은 시간이 크게 보이고, 사용자가 직접 만든 동작 이미지가 중앙에 배치되어야 해.

모바일 터치에 최적화된 큰 버튼과 직관적인 슬라이더를 사용해줘.

[단계별 작업 요청]

먼저 50가지 운동 데이터가 담긴 exercises.json 파일을 만들어줘.

타이머 로직(운동-휴식 전환)을 담당하는 커스텀 훅(useTimer)을 작성해줘.

메인 대시보드와 타이머 실행 화면 UI 코드를 작성해줘.

배경음악 및 알림음 재생을 위한 오디오 관리 로직을 구현해줘.

[코드 검증 및 디버깅 가이드]

작업 완료 후에는 다음 사항을 반드시 체크해줘:

메인 페이지(Home)에 제시된 4가지 운동(푸쉬업, 스쿼트, 런지, 플랭크)이 화면에 렌더링되는지 확인.

운동 이름 아래에 있는 시간 설정 슬라이더를 움직여보고, 운동 중 타이머가 5초 단위로 정확하게 감소하는지 확인.

'Start Timer' 버튼 클릭 시 배경음악과 함께 운동 시퀀스(25초 운동 / 5초 휴식)가 자동으로 실행되는지 확인.

모바일 화면(가로 모드 포함)에서도 UI가 깨지지 않고 터치 조작이 원활한지 확인.

아이폰의 홈 화면에 추가(Add to Home Screen) 기능이 정상적으로 동작하는지 확인.
